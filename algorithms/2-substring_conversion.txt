TITLE: Replace Substring 'abc' with 'ABC' using LEX

ALGORITHM:
Step 1: Start.
Step 2: In the Lex rules section, define pattern-action pairs:
        - When the exact string "abc" is matched, print "ABC".
        - When any other character (.) is matched, print the character as-is (yytext).
        - When a newline (\n) is matched, print the newline.
Step 3: In the main function, display a prompt asking the user to enter an input string.
Step 4: Invoke yylex() to scan and process characters from standard input.
Step 5: Output the transformed string to standard output.
Step 6: Stop.
