TITLE: Lexical Analyzer for C Language Tokens using LEX

ALGORITHM:
Step 1: Start.
Step 2: Define regular definitions:
        - DIGIT     : [0-9]
        - LETTER    : [a-zA-Z_]
        - ID        : {LETTER}({LETTER}|{DIGIT})*
        - INT_NUM   : {DIGIT}+
        - FLOAT_NUM : {DIGIT}+"."{DIGIT}+
        - WS        : [ \t\n]+
Step 3: In the rules section, specify token recognition actions:
        - Skip multi-line comments "/*" ... "*/" and single-line comments "//".
        - Skip whitespace, tabs, and newlines.
        - Recognize C keywords (int, float, char, if, else, while, for, return, void, break, etc.) and print "[KEYWORD] : yytext".
        - Recognize identifiers {ID} and print "[IDENTIFIER] : yytext".
        - Recognize floating-point numbers {FLOAT_NUM} and integers {INT_NUM} and print "[FLOAT_LIT]" or "[INT_LIT]".
        - Recognize arithmetic, relational, and logical operators (==, !=, <=, >=, &&, ||, ++, --, +, -, *, /, %, =, <, >) and print "[OPERATOR] : yytext".
        - Recognize delimiters and punctuation ({, }, (, ), [, ], ;, ,, .) and print "[DELIMITER] : yytext".
        - Any unrecognized character (.) is printed as "[UNKNOWN] : yytext".
Step 4: In the main function, call yylex() to scan the input stream and classify tokens.
Step 5: Stop.
